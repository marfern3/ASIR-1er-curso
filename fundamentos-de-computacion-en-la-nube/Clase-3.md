## ☁️ Modalidades de Nubes
![Modalidades de nube](e4b33b47-7e49-4157-b25e-b638cba182cd.png)

---

### 1️⃣ NUBE PRIVADA 🔐
Infraestructura de nube **exclusiva para una sola organización**, ya sea alojada internamente o por un tercero.  
Usada para procesamiento de **datos sensibles** o en entornos con requisitos de cumplimiento normativo.

**Ventajas:**
- Mayor control y seguridad  
- Personalización según necesidades  
- Mayor coste de mantenimiento  

**Ejemplos:** VMware vCloud, OpenStack, Microsoft Azure Stack

---

### 2️⃣ NUBE HÍBRIDA 👐
Combinación de nubes **públicas y privadas** que trabajan juntas, permitiendo mover datos y aplicaciones entre ambas.  
Ideal para **migraciones graduales** a la nube y para gestionar picos de demanda.

**Ventajas:**
- Flexibilidad y equilibrio entre seguridad y escalabilidad  
- Integración de recursos locales y externos  

**Ejemplos:** IBM Hybrid Cloud, Google Anthos, Azure Arc

---

### 3️⃣ NUBE PÚBLICA 🚶‍♀️‍➡️
Infraestructura ofrecida por un **proveedor externo** a través de Internet, compartida entre múltiples usuarios.  
Usada para aplicaciones web, almacenamiento masivo y copias de seguridad.

**Ventajas:**
- Escalable y flexible  
- Pago por uso  
- Mantenimiento a cargo del proveedor  

**Ejemplos:** Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform

## 2️⃣ INTRODUCCIÓN A AWS - AMAZON WEB SERVICES

AWS (Amazon Web Services) nació en **2006**, cuando Amazon necesitaba una infraestructura más **eficiente y escalable** para manejar su negocio.

Durante ese proceso, descubrieron que muchas empresas tenían los mismos problemas:  
- Falta de capacidad  
- Altos costos  
- Dificultad para escalar sistemas  

Por ello, decidieron ofrecer su **infraestructura como servicio**, permitiendo a otras organizaciones usar sus recursos informáticos (**servidores, almacenamiento, bases de datos, etc.**) bajo demanda y pagando solo por lo que utilizan.

👉 **AWS nació para ofrecer servicios en la nube escalables, flexibles y económicos a terceros.**
